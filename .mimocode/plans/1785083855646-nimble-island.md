## Execution Strategy

All implementation tasks below are executed via **Claude Code CLI** in print mode (`-p`), not directly by the orchestrator. Each task is a one-shot `claude -p` invocation with:

- `--allowedTools` scoped to least privilege (Read, Edit, Write, Bash, Glob, Grep as needed)
- `--max-turns` set per task complexity (5-15)
- `--output-format json` for structured results
- `workdir` set to `/home/asamo/Octopus-Agent`

The orchestrator dispatches tasks sequentially (or in parallel where independent), reviews Claude Code's output, verifies with tests, and proceeds to the next task.

### Delegation Template

```bash
claude -p '<task description>' \
  --allowedTools 'Read,Edit,Write,Bash,Glob,Grep' \
  --max-turns 10 \
  --output-format json
```

For read-only tasks (verification, exploration):
```bash
claude -p '<task description>' \
  --allowedTools 'Read,Bash,Glob,Grep' \
  --max-turns 5 \
  --output-format json
```
